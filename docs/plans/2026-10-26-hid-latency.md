# HID 读取延迟优化

用户批准实施 HID 锁精简、同步完成快速路径与双缓冲实验，并允许删除影响热路径的显示统计。本轮聚焦 HID 延迟，不扩展设备驱动恢复或改变输入映射。

1. 冻结 1.0.2 当前源码和匹配库到 `artifacts/latency-hid/baseline`，保留哈希清单。
2. 以真实 `hid_session` 和受控 Win32 I/O 建立回归保护：同步/异步报告、按下释放、短包、重投失败、停止/切换及取消生命周期。
3. HID 每份报告合并到一次提交锁；同步完成不再调用多对象等待。双缓冲仅保留一个未完成请求，先续读再解析；用 A/B 决定是否保留。
4. 默认 HID 关闭逐报告 QPC、浮点延迟计算及统计窗口，保留基本输入/错误计数。已有 `PS5BRIDGE_TRACE=1` 恢复计时；ABI 6 与 XInput 统计保持兼容。界面正确显示缺失计时。
5. 受控 1K/高频报告源执行真实加密 UDP 环回，交替对比改前/改后，区分源调度、应用处理与端到端延迟。测试不冒充真实 USB 或 PS5。
6. 完成原生、托管、离线 UI 验证，更新说明和本地发行包。

保留全部输入边沿、不合并摇杆、不更改死区/曲线、首次同步发送和补发语义；不改变 Windows 或 USB 设置。
