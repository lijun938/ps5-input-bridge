# 账户管理与使用体验验证

2026-10-23，Windows x64、.NET SDK 9.0.312、Python 3.11、项目固定 LLVM-MinGW 工具链。用户确认问题来自 Chiaki 导入；保留此前未提交的导入与延迟优化，以及 100 / 500 / 1000 μs 三档，默认 500 μs。

## 两个反馈问题

1. **导入后无法命名、命名后连接失败**：原导入预览的名称只读，唯一文本框实际绑定 Host。使用五个合成配对记录复现，向该框输入昵称会把 IP 改成昵称，名称仍不变；合法的主机名语法也不能证明地址可连接。现在名称、地址分别可编辑，并明确用途，确认导入只改变对应字段，保留凭据。已导入的错误地址可以通过“编辑名称 / 地址”修正，无需重新配对。
2. **没有删除入口**：账户区新增“删除账户”，默认取消的确认框说明仅移除本程序记录。删除后可重新导入，不修改 Chiaki 或 PS5 的记录。删除当前账户先停止会话，之后不自动连接其他账户；保存失败保留原列表。

五账户独立名称的 UI 回归在旧界面上失败，修复后通过。另检查空名称的针对性提示、取消编辑、连接中改名不停止、改地址先停止、连接中删除、最后一个账户删除及存储失败。

## 使用体验与可靠性

- 导入、导出和添加入口收进展开区，常用的账户选择、编辑、删除直接可见。
- 独立 preferences.json 保存账户、手柄、采样档和 Back 映射；启动恢复选择但不自动连接。写入按顺序执行，关闭等待完成；账户切换不等待磁盘写入后再连接，避免慢保存导致重复连接。
- 连接后的手柄、采样档和 Back 映射调整直接生效，不重新建立 PS5 会话。HID 模式禁用无效的采样选项并保留 XInput 档位。
- HID 绑定设备接口路径，避免枚举顺序变化选错手柄。离线、打开失败、读取失败有独立状态与提示。USB 口变化或 USB / 蓝牙切换后，路径可能不同，需要重新选择。
- ABI 升级为 5；原生、Python、托管布局检查覆盖 1608 字节设备信息及 8 字节手柄状态。旧 DLL 会被版本检查拒绝，必须使用完整新发行目录。
- 切换设备先释放旧输入，不等待新 HID 第一份报告；切换期间的旧 XInput 样本被丢弃，未成功发送的旧输入也被替换。每次已观察到的切换只注入一次 neutral，避免失败时重复插入。新增 3 项回归覆盖这些边界；旧实现的样本竞争和首包等待用例先失败，修复后通过。
- 每 Windows 用户使用 Global mutex 限制一个实例，防止多个窗口覆盖账户。离线检查验证互斥获取、拒绝和释放；未做真实 RDP 多会话运行测试。
- 账户包密码派生在后台完成，提供忙状态；限制 1 MB、64 个账户及既有格式的 300000 次 PBKDF2 参数，验证账户与重复 Id，清理临时密钥和明文。兼容本程序已有导出格式。
- 诊断最多保留 256 条变化事件，只输出白名单状态、数值错误码、输入计数、设置与延迟统计；不导出账户名、地址、设备路径、凭据、PIN、令牌或原始错误消息。

需求复核指出的诊断字段缺失、选择事件等待偏好保存、删除测试未启用真实事件条件均已补齐。独立质量复核指出的 HID 首包前残留输入及跨会话互斥缺口已修复；最终复核未发现交付阻断项。
